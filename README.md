# 🧮 JavaScript Calculator App

A simple, modern, and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Live Demo

🔗 **GitHub Repository:**
https://github.com/rajputayushsingh/JS-Calculator-App

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Modulus
* 🔢 Decimal number support
* 🗑️ Delete last digit
* 🔄 Clear/Reset calculator
* ⚠️ Division-by-zero error handling
* 📱 Responsive and clean UI
* ✨ Interactive button effects

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and responsive layout
* **JavaScript** – Calculator logic and DOM manipulation

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/rajputayushsingh/JS-Calculator-App.git
```

### 2. Open the project

```bash
cd JS-Calculator-App
```

### 3. Run the application

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.
